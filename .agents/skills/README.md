# Agent Skills Suite for Fish

This directory contains specialized AI Agent Skills tailored for developing, debugging, optimizing, and maintaining the Fish build orchestration engine across all supported language ecosystems.

## Included Skills

- **Rust Systems & Async**: `rust-pro`, `rust-async-patterns`, `systems-programming-rust-project`
- **Golang Networking**: `golang-pro`, `grpc-golang`
- **Python AI & Optimization**: `python-pro`, `python-development`, `async-python-patterns`, `python-patterns`, `python-performance-optimization`
- **TypeScript & Web / IDE**: `typescript-pro`, `typescript-expert`, `typescript-advanced-types`, `frontend-developer`, `frontend-design`, `web-performance-optimization`, `web-design-guidelines`
- **Documentation & VitePress**: `wiki-vitepress`, `docs-architect`, `documentation`, `api-documentation`
- **DevOps, Shell & Diagnostics**: `docker-expert`, `kubernetes-deployment`, `bash-pro`, `powershell-windows`, `windows-shell-reliability`, `debugging-toolkit-smart-debug`, `systematic-debugging`, `performance-profiling`, `c-pro`
