# Agent Skills Suite for Fish

This directory contains specialized AI Agent Skills tailored for developing, debugging, optimizing, and maintaining the Fish build orchestration engine across all supported language ecosystems.

## 📚 Categorized Skills Index

### 🦀 Rust Systems, Memory Safety & Concurrency
- `rust-pro`: Advanced async runtime, zero-copy, lifetime management, and Rust 2024 idioms.
- `rust-async-patterns`: Tokio runtime optimization, stream pipelines, actors, and lock-free channels.
- `systems-programming-rust-project`: Low-level system programming and resource management.
- `memory-safety-patterns`: Hardening invariants and eliminating data races.
- `zeroize-audit`: Zero-allocation and memory zeroization security practices.

### 🐹 Golang Distributed Networking
- `golang-pro`: Go 1.22+ concurrency, buffered channels, context lifecycle, and race prevention.
- `go-concurrency-patterns`: High-throughput pipeline and worker pool patterns.
- `grpc-golang`: High-speed RPC transport and Protobuf serialization.
- `temporal-golang-pro`: Resilient distributed workflow orchestration.

### 🐍 Python AI, Optimization & ML
- `python-pro`: Production Python 3.11+ patterns, strict type annotations, and performance.
- `python-development`: Packaging, environment management, and modular architecture.
- `async-python-patterns`: Non-blocking async event loops and coroutine management.
- `python-patterns`: Idiomatic design patterns and clean architectures.
- `python-performance-optimization`: Profiling, memory optimization, and fast numerical computing.
- `python-testing-patterns`: Comprehensive unit test harnesses and property-based testing.
- `fastapi-pro`: Production-ready async REST APIs with automated OpenAPI contracts.
- `pydantic-models-py`: Schema modeling and strict input validation.

### 📘 TypeScript, Web, UI & VS Code Extension
- `typescript-pro`: Strict TypeScript engineering, generic constraints, and module bundlers.
- `typescript-expert`: Deep type narrowing, conditional types, and utility schemas.
- `typescript-advanced-types`: Advanced compiler-level type safety.
- `modern-javascript-patterns`: Modern ESNext idioms and clean asynchronous code.
- `frontend-developer`: Modern web frontend development standards.
- `frontend-design`: High-aesthetic UI and accessible component architecture.
- `web-performance-optimization`: Core Web Vitals, tree-shaking, and latency reduction.
- `web-design-guidelines`: Web interface compliance and usability guidelines.
- `vscode-extension-guide-en`: VS Code Language Server Protocol and extension development guide.

### ⚙️ Native C/C++ Toolchains
- `c-pro`: Low-level C programming, compiler flags, and memory management.
- `cpp-pro`: Modern C++20/23 idioms, standard template libraries, and RAII.

### 📖 Documentation, VitePress & API Specs
- `wiki-vitepress`: Building and maintaining VitePress documentation sites.
- `docs-architect`: Structuring technical documentation catalogues and guides.
- `documentation`: Clear code documentation and rustdoc best practices.
- `api-documentation`: API documentation generator and contract management.
- `openapi-spec-generation`: Automated schema synchronization and API documentation.

### 🐳 DevOps, Containers, Kubernetes & Shell
- `docker-expert`: Multi-stage Docker builds, image slimming, and container security.
- `kubernetes-architect`: Production-grade cluster architecture and topologies.
- `kubernetes-deployment`: K8s manifests, deployments, and stateful sets.
- `bash-pro`: Robust POSIX/Linux shell automation and error trapping.
- `bash-defensive-patterns`: Defensive shell programming paradigms.
- `powershell-windows`: Idiomatic PowerShell scripts on Windows environments.
- `windows-shell-reliability`: Reliable path escaping, process spawning, and Windows encoding.

### 🔍 Architecture, Performance & Diagnostics
- `architecture`: High-level system architecture and modular component design.
- `senior-architect`: Clean architectural decisions, trade-offs, and scalability.
- `performance-profiling`: CPU/memory profiling, flamegraphs, and benchmarking.
- `performance-engineer`: Latency reduction, throughput optimization, and bottleneck analysis.
- `systematic-debugging`: Scientific bug reproduction, root-cause isolation, and bisecting.
- `debugging-toolkit-smart-debug`: Advanced multi-layered debugging workflows.
- `code-reviewer`: Invariant verification and elite code review standards.
- `codebase-audit-pre-push`: Pre-push hygiene and security audit checklists.
- `tdd-workflow`: Red-Green-Refactor test-driven development workflow.
