# Language Backends

Fish provides native build orchestration adapters for 11+ programming language toolchains:

- [Rust](rust.md) - Cargo & rustc integration
- [Go](go.md) - Go modules & toolchain
- [TypeScript / JavaScript](typescript.md) - Node.js, npm, pnpm, yarn, bun
- [Python](python.md) - pyproject.toml, uv, pytest
- [C / C++](cc.md) - CMake, Make, Clang, GCC, MSVC
- [Docker](docker.md) - Containerized build orchestration
- [Java / Kotlin](java.md) - Maven & Gradle
- [Dotnet](dotnet.md) - .NET SDK & MSBuild
