# Fish AI Agent 開発ワークフローガイド

> 🌐 **翻訳と貢献:** このドキュメントをあなたの言語で翻訳または改善したいですか？ [翻訳ガイドライン](TRANSLATION.md) をご覧ください。

このドキュメントは、Fish ビルドオーケストレーションシステムで作業する AI コーディングエージェント向けの詳細なステップバイステップ手順書です。

## 🎯 概要

このガイドラインは以下を目的としています：
- バグやエラーの混入を最小限に抑制。
- プロジェクトの安定した稼働を確保。
- コード品質とアーキテクチャの一貫性を維持。
- プロジェクト固有のベストプラクティスを遵守。

---

## 📖 フェーズ 1: 事前コンテキストの収集

### ステップ 1.1: 必須ドキュメントの確認（必須）

1. **README.md** - プロジェクト概要、クイックスタート
2. **Cargo.toml** - ワークスペース構造、MSRV要件 (1.88+)
3. **ARCHITECTURE.md** - システムアーキテクチャと責務
4. **DEVELOPMENT.md** - ローカル開発環境のセットアップ

---

## 💻 フェーズ 2: 実装規約

- Rust 2024 edition の規約に従う。
- エラーハンドリング: アプリ層は `anyhow`、ライブラリ層は `thiserror` を使用。
- 関数名、変数名、コミットメッセージは**すべて英語**で記述。

---

## 🔍 フェーズ 3: 品質検証

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace
```
