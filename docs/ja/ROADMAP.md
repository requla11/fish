このドキュメントは、完了したマイルストーンから短期・中期目標、長期ビジョン、および研究トラックに至るFishの戦略的開発ロードマップの概要を示します。

---

## 🎯 ビジョン

Fishは、単一言語の**Rustコア（28クレート、Rust 2024、MSRV 1.88+）と11の多言語バックエンド**を原動力として、ポリグロットモノレポおよび分散開発環境向けに最も効率的で堅牢、かつ開発者に優しいビルドオーケストレーションシステムを目指しています。

私たちが最優先で最適化する目標：

1. **実経過時間（Wall-clock time）** — エンドユーザーが直接体感する唯一の指標。
2. **キャッシュ効率** — ヒット率、マシン間および地域間でのアーティファクト再利用。
3. **信頼性** — キャッシュされたすべてのバイトが入力と正確に一致することの検証。
4. **ツールの誠実さ** — 虚偽の診断や成功の偽装を排除。

- [x] **5言語ドキュメント**: GitHub Pages上で公開（英語、ベトナム語、簡体字中国語、繁体字中国語、日本語）。
