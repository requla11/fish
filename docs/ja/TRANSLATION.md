# ドキュメント翻訳・ローカライズ貢献ガイド

> 🌐 コミュニティからの Fish ドキュメントの**あらゆる言語**への翻訳貢献を心より歓迎します。

このドキュメントでは、翻訳手順、透明性ポリシー、貢献ガイドラインについて説明します。

## 翻訳の対象範囲

`docs/` ディレクトリ配下の **Markdown ドキュメント** のみが翻訳対象です。

- **ソースコード、テスト、関数・変数名、コミットメッセージ** は **100% 英語** を維持してください。
- **CLI コマンド名、フラグ（--flag）、コード例、設定キー** は翻訳しないでください。

## コントリビューター向けポリシー

1. **部分的な翻訳・段階的な翻訳も歓迎**: ドキュメント全体を一括で翻訳する必要はなく、1つのセクションだけの翻訳も歓迎されます。
2. **ローカルの Rust 環境構築は不要**: GitHub Web 上のエディタから直接編集・プルリクエスト作成が可能です。
3. **スピーディーなレビュー**: 翻訳および誤字修正の PR は優先的にレビュー・マージされます。

## サポートされている 5 つの公式コア言語

| 言語 | コード | ステータス |
| :--- | :--- | :--- |
| **English** (英語) | `en` | 公式基準ソース |
| **日本語** | `ja` | コアコミュニティ言語 |
| **Tiếng Việt** (ベトナム語) | `vi` | コアコミュニティ言語 |
| **Simplified Chinese** (簡体字中国語) | `zh-hans` | コアコミュニティ言語 |
| **Traditional Chinese** (繁体字中国語) | `zh-hant` | コアコミュニティ言語 |
