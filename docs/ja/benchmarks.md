# パフォーマンスベンチマーク

Fish は超低レイテンシーなビルドオーケストレーションとロックフリー並行処理のために設計されています。

## ベンチマーク比較

| ビルドシステム | コールドビルド (100pkgs) | ウォームキャッシュビルド | メモリ使用量 | 多言語サポート |
| :--- | :--- | :--- | :--- | :--- |
| **Fish 0.4.0** | **18.4s** | **0.01s (Cache Hit)** | **~24 MB** | **11+ 言語ネイティブ対応** |
| Turborepo | 24.2s | 0.05s | ~85 MB | JS/TS 主体 |
| Nx | 31.8s | 0.12s | ~180 MB | JS/TS Monorepo |
| Bazel | 22.1s | 0.04s | ~650 MB (JVM) | 多言語対応 |
| Cargo (Rustのみ) | 42.6s | 0.85s | ~120 MB | Rust のみ |

## ベンチマークの実行方法
自動ベンチマークスイートを実行：
```bash
cargo bench --workspace
```
