# 変更履歴とバージョン情報

Fish プロジェクトの重要な変更履歴です。

## [v0.3.0] - 2026-08-21
### 新機能
- **IDE 拡張機能**: 公式 VS Code 拡張機能および JetBrains プラグインスイート。
- **LSP サポート**: `fish lsp` 言語サーバーと構文診断。
- **gRPC REAPI v2**: リモート実行 API v2 とアクションキャッシュ。
- **eBPF トレース**: Linux カーネルレベルの動的依存関係検出。
- **Doctor AI**: 対話型環境診断と修復 (`fish doctor --fix`)。
- **TUI ダッシュボード**: リアルタイム Waterfall タスク可視化。

## [v0.2.0] - 2026-08-10
### 新機能
- **Tri-Engine アーキテクチャ**: Rust 2024 コア + Go コーディネーター + Python AI。
- **11 言語バックエンド**: Rust, Go, TS, Python, C++, Docker, Java, .NET, Swift, Dart, Zig。
- **BLAKE3 CAS ストレージ**: ZSTD 圧縮コンテンツアドレスキャッシュ。
