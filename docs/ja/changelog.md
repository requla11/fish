# 変更履歴とリリースノート

Fish プロジェクトにおけるすべての主要な変更はここに記録されます。

フォーマットは [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) に基づき、[セマンティック バージョニング](https://semver.org/spec/v2.0.0.html) に準拠します。

## [v0.6.0] - 2026-08-25

### 追加
- **言語間 Protobuf プロトコル**: 外部コンパイラバイナリに依存せず、Rust、Go、Python 間でバイナリ Google Protocol Buffers wire 形式の相互変換を実現。
- **Wasm プラグインエンジンとセキュリティ監査**: サンドボックス化された WebAssembly プラグイン機構、権限ケーパビリティ監査（`fish plugin audit`）、および Ed25519 電子署名検証。
- **ZSTD コンテンツアドレス指定ストレージ (CAS)**: 超高速 BLAKE3 ツリーハッシュとマルチスレッド Zstandard 圧縮による決定論的 L1/L2 ビルドキャッシュ基盤。
- **11 のポリグロット言語バックエンド**: Rust、Go、TypeScript/Node、Python、C/C++、Docker、Java、.NET、Swift、Dart、Zig へのネイティブゼロコンフィグ対応。
- **適応型並列処理とワークスティーリング**: Chase-Lev デックによる分散型ワークスティーリングスケジューラ、クリティカルパステール優先、および RAM メモリ保護制御。

### 改善
- 依存循環（Cycle）の検出時に、単一のエラーではなく閉じた完全なパスを明示するように改善。
- ローカルキャッシュヒット時、宣言されたタスク成果物を自動的にディスクへ展開・復元するように改修。

## [v0.5.0] - 2026-08-24

### 追加
- **5言語対応ドキュメントポータル**: 英語、ベトナム語、簡体字中国語、繁体字中国語、日本語に対応した完全な VitePress ドキュメント基盤。
- **分散コーディネーター (Go)**: ワーカーのハートビート追跡と HTTP/Protobuf タスク配信を備えた高スループットコーディネーター。
- **AI 障害分析と自動修復 (Python)**: サブプロセスパイプラインによるコンパイラ診断の解析と予測的キャッシュウォーミング。

## [v0.3.0] - 2026-08-21

### 追加
- **IDE 拡張機能**: 公式 VS Code 拡張機能および Language Server Protocol (`fish lsp`) 統合。
- **インタラクティブ TUI ダッシュボード**: リアルタイムなマルチスレッド進行状況、CPU/RAM 使用率、ウォーターフォール可視化。
- **eBPF トレーシング**: Linux カーネル空間での動的ファイルアクセスと依存関係の自動検出。

## [v0.2.0] - 2026-08-10

### 追加
- **Tri-Engine コアアーキテクチャ**: Rust 2024 コアエンジンと補助的な Go 分散ネットワーク、Python AI サービスの連携。
- **フィンガープリントキャッシュエンジン**: BLAKE3 による高速なタスクキャッシュキー計算と差分検知。
- **GNU Jobserver プール**: コンパイラの競合を防ぐグローバルな並列度ガバナンス。

## [v0.1.0] - 2026-08-01

### 追加
- Rust および TypeScript バックエンドをサポートした Fish の初期実験的リリース。
