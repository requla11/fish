# サンプルプロジェクト & スターター

Fish ワークスペースに含まれる実践的なポリグロットサンプル集です。

## 利用可能なサンプル
1. **`examples/polyglot-demo`**: Rust TCP バックエンド、Go サービス、TypeScript Web、Docker Compose。
2. **`examples/ai-microservices`**: Rust トークナイザー、Python FastAPI 推論、Go ゲートウェイ。
3. **`examples/fullstack-wasm`**: Rust WebAssembly コア、TypeScript クライアント、C++ ネイティブ計算モジュール。

## サンプルの実行
```bash
cd examples/ai-microservices
fish build
fish test
```
