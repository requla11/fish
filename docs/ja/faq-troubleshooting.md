## よくある質問

### 1. Fish は Cargo や Turborepo、Bazel と何が違いますか？
Fish は多言語モノレポ専用に設計されており、Rust のネイティブな高速実行、Python AI による高度な最適化、Go によるクラウド分散ネットワーキングを統合しています。Bazel のような複雑な設定なしですぐに使えます。

### 2. サポートされている言語は何ですか？
現在 11 種類の主要言語・バックエンドをサポートしています：Rust、Go、TypeScript/Node.js、Python、C/C++、Docker、Java、.NET、Swift、Dart、Zig。

### 3. 環境診断を実行するには？
以下のコマンドを実行します：
```bash
fish doctor --ai
```

## トラブルシューティング

### Windows でのページングファイル枯渇 (`os error 1455`)
- **原因:** 並行ビルド数が多すぎてメモリ・ページファイルが不足しています。
- **解決策:** `--jobs` オプションで並行数を制限します：
```bash
fish build --jobs 4
```
