# プロジェクトメンテナーとガバナンス (Maintainers)

Fish プロジェクトのメンテナーチームとガバナンス構造について説明します。

## プロジェクトリーダーシップ
- **プロジェクトリード**: Foursavage Dev Team (`foursavage@proton.me`)
- **アーキテクチャ & コア**: Rust 2024 ワークスペースチーム
- **クラウド & 分散ネットワーク**: Go 分散システムグループ
- **AI & 予測エンジン**: Python AI チーム

## レビュープロセス
すべての Pull Request は、`dev` または `main` にマージされる前に関連サブシステムのメンテナーによるレビューが必要です。
