# リリース v0.3.0 — Tri-Engine アーキテクチャ、11 言語バックエンド、ポリグロットサンプル & 極限のパフォーマンス

> ⚠️ **正確性に関する注記（遡及的追加）：** この歴史的リリースノートは、**リポジトリにマージされなかった**コンポーネント（`go/` サービス、`py/` AI エンジン、VS Code 拡張機能、gRPC トランスポート）について記述しています。執筆時点では将来の構想でした。Fish は現在も純粋な Rust ワークスペースです。実際に提供されている機能については [architecture.md](/ja/architecture) を参照してください。

## 📌 概要

本リリースは公式 **Fish v0.3.0 リリース** を確立し、完全な Tri-Engine アーキテクチャ、11 種類のプロダクショングレード言語バックエンド、実践的なポリグロット参照サンプル、充実した 5 言語ドキュメント、および徹底的なパフォーマンス最適化を導入します。

## 🚀 主なハイライトと機能

### 1. 🏗️ Tri-Engine アーキテクチャ (36 Crates)
- **Rust Core (Rust 2024, MSRV 1.88+)**：完全疎結合の DAG マージャー、Chase-Lev ワークスティーリングスケジューラ、GNU Jobserver プール、ZSTD 圧縮付きコンテンツアドレス指定ストレージ (CAS)、およびマルチティア L1/L2 キャッシュ。
- **分散 Go サービス (`go/`)**：高スループット Coordinator、P2P メッシュルーター、Worker ゲートウェイ、およびリトルの法則（Little's Law）で最適化された Kubernetes オートスケーラー。
- **Python AI エンジン (`py/`)**：リアルタイム所要時間予測モデル、投機的プリウォーミング、および予測的 AST 自動修正。
- **VS Code 拡張機能 (`vscode-extension/`)**：LSP 統合とリアルタイム DAG タスク検査を備えたネイティブ TypeScript 拡張機能。

### 2. 🌐 完全な 11 言語バックエンド
- **自動検出 & ゼロ構成（Zero-Config）オーケストレーション**：
  - `Rust`（Cargo メタデータ、cargo-nextest、パイプライン化 rmeta）。
  - `C/C++`（GCC、Clang、MSVC 自動検出 & depfiles 依存関係ファイル）。
  - `Go`（go.mod、go build、go test、go vet）。
  - `TypeScript/JavaScript`（npm、pnpm、yarn、bun、tsc）。
  - `Python`（pyproject.toml、pytest、uv、pex パッケージング）。
  - `Java`（Maven & Gradle 統合）。
  - `.NET`（dotnet CLI、.csproj、.sln 自動検出）。
  - `Swift`（Package.swift、swift build）。
  - `Dart`（pubspec.yaml、dart test、dart compile）。
  - `Zig`（build.zig、zig build）。
  - `Docker`（マルチステージ Dockerfile & Compose オーケストレーション）。

### 3. ⚡ 極限のパフォーマンス & ベンチマーク成果
**Criterion** ベンチマークスイートによる検証：
- **DAG トポロジカルソート**：ゼロ割り当てのダイレクトビットセットインデックスにより、50〜1,000 タスクにおいて**レイテンシを 25.5% 〜 41.6% 削減**。
- **L1 インメモリ並行キャッシュ**：反復クエリでディスク I/O をバイパスし、**キャッシュ照合を 50.2% 高速化**（`55.08 µs` $\to$ `27.57 µs`）。
- **スケジューラ先読み**：逆トポロジカル動的計画法（$O(V+E)$ シングルパス）による最長テールパス長とクリティカルパススコアリングの即時算出。
- **Zero-Copy I/O**：子プロセス stdout/stderr バッファの直接 UTF-8 所有権移転。
- **Release Profile**：全体リンク時最適化 (`lto = "fat"`)、`opt-level = 3`、`codegen-units = 1`。

### 4. 💡 ポリグロット参照アーキテクチャ (`examples/`)
- **`examples/ai-microservices`**：Rust トークナイザー + Python FastAPI 推論 + Go ゲートウェイ（ウォームビルド：**0.46s**）。
- **`examples/fullstack-wasm`**：Rust WASM コア + TypeScript クライアント + C++ ネイティブアクセラレータ（ウォームビルド：**0.18s**）。
- **`examples/polyglot-demo`**：Docker オーケストレーションによるフルスタックマイクロサービス構成。

### 5. 📚 ドキュメント & 5 言語ローカライズ

  - 🇺🇸 英語 (`en`)

  - 🇨🇳 簡体字中国語 (`zh-hans`)
  - 🇹🇼 繁体字中国語 (`zh-hant`)
  - 🇯🇵 日本語 (`ja`)

## 📦 主な変更点
- GCC/Clang/MSVC ツールチェーン向けの Windows UNC パスプレフィックスを正規化。
- リモートキャッシュテストハーネスにおいて競合のないエフェメラルポート割り当てを実装。
- 2 フェーズ GC クリーンアップを備えた並行 L1 インメモリキャッシュを統合。
- `fish init` で 11 種類の全バックエンドエコシステムの自動検出を包括的にサポート。
