## Reporting a Vulnerability

If you discover a security vulnerability in Fish, please **do not** open a public issue. Instead, report it privately via email:

- **Security Email**: [foursavage@proton.me](mailto:foursavage@proton.me)

We will acknowledge receipt of your report within 48 hours and provide a timeline for remediation.
