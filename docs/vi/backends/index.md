# Backend Ngôn ngữ

Fish cung cấp các bộ điều hợp (adapter) điều phối biên dịch cho hơn 11 ngôn ngữ và chuỗi công cụ:

- [Rust](rust.md) - Tích hợp Cargo & rustc
- [Go](go.md) - Quản lý Go modules
- [TypeScript / JavaScript](typescript.md) - Node.js, npm, pnpm, yarn, bun
- [Python](python.md) - pyproject.toml, uv, pytest
- [C / C++](cc.md) - CMake, Make, Clang, GCC, MSVC
- [Docker](docker.md) - Điều phối biên dịch container
- [Java / Kotlin](java.md) - Maven & Gradle
- [Dotnet](dotnet.md) - .NET SDK & MSBuild
