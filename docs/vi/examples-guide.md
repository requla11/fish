# Dự Án Mẫu & Khởi Tạo Đa Ngôn Ngữ

Khám phá các mẫu dự án monorepo đa ngôn ngữ thực tế có sẵn trong Fish.

## Danh Sách Ví Dụ
1. **`examples/polyglot-demo`**: Ngăn xếp web đa ngôn ngữ gồm Rust backend, Go microservice, TypeScript web và Docker Compose.
2. **`examples/ai-microservices`**: Pipeline AI phối hợp giữa Rust Tokenizer siêu tốc, Python FastAPI dự đoán mô hình và Go Gateway proxy.
3. **`examples/fullstack-wasm`**: Ứng dụng Wasm hiệu năng cao kết hợp lõi Rust WebAssembly, TypeScript client và module tính toán C++ native.

## Chạy Thử
```bash
cd examples/ai-microservices
fish build
fish test
```
