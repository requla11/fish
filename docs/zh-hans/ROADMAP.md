# Fish 项目发展路线图 (Roadmap)

> 🌐 **翻译与贡献：** 想用您的母语翻译或完善本文档？请查看 [翻译指南](TRANSLATION.md)。

本文档阐述了 Fish 项目的战略发展路线图，涵盖已完成里程碑、近期目标、中期规划以及长期远景。

---

## 🎯 项目愿景

Fish 致力于成为多语言单体大仓（Polyglot Monorepo）与分布式开发环境中性能最高、最安全且对开发者最友好的构建编排系统，由独特的 **三引擎架构 (Rust 75% + Python 15% + Go 10%)** 强力驱动。

---

## 🚀 当前里程碑 (v0.2.x) — 已完成

### 第一阶段：核心引擎与多语言基石
- [x] **三引擎架构**：Rust 高性能执行核心 (75%)、Python AI 智能层 (15%) 与 Go 云原生网络服务 (10%)。
- [x] **11 种后端语言支持**：Rust、Go、TypeScript/Node.js、Python、C/C++、Docker、Java、.NET、Swift、Dart、Zig。
- [x] **通用 Protobuf 契约**：制定了 `build.proto`、`ai.proto` 与 `coordinator.proto`。
- [x] **Blake3 CAS 与两阶段修剪**：高吞吐内容寻址制品存储，支持 Zstandard 压缩。
- [x] **GNU Jobserver 调度集成**：跨编译器全局线程令牌协调，防止 CPU/内存过载。
- [x] **CI/CD 工作流生成器**：支持 GitHub Actions、GitLab CI、CircleCI、Bitbucket。
- [x] **5 语言官方文档体系**：全面上线 GitHub Pages（英语、中文简体、中文繁体、日语、越南语）。

---

## ⚡ 短期目标 (v0.3.x) — 核心重点：开发体验与协议通道

### 1. IDE 与编辑器深度集成
- [ ] **VS Code 官方扩展**：交互式 DAG 依赖图可视化、一键运行构建任务与内联错误诊断。
- [ ] **JetBrains 插件套件**：适用于 CLion、IntelliJ IDEA 与 Rider 的原生插件。
- [ ] **LSP (语言服务器协议) 桥接**：`fish.toml` 智能补全与工作区实时诊断。

### 2. 高性能 IPC 与通信协议
- [ ] **守护进程 IPC 数据流**：Rust CLI 与 Python AI 之间亚毫秒级 JSON-RPC 管道。
- [ ] **gRPC Remote Execution API (REAPI)**：支持标准分布式远程执行协议。
- [ ] **eBPF 文件系统追踪**：Linux 内核层精准捕获输入输出文件变动。

### 3. 智能诊断工具优化
- [ ] **AI 交互式 Doctor 医生**：主动检测环境问题并提供自动修复命令 (`fish doctor --fix`)。
- [ ] **TUI 终端界面升级**：实时 CPU/RAM 监控图表与多任务瀑布流展示。

---

## 🌟 中期目标 (v0.4.x - v0.5.x) — 核心重点：云原生分布式与 AI

### 1. 云原生分布式基础设施
- [ ] **Kubernetes Operator (Go)**：根据构建负载动态伸缩分布式 Worker Pod 集群。
- [ ] **竞价实例（Spot Instance）弹性优化**：节点被回收时任务无损迁移。
- [ ] **跨地域 P2P 快取分发**：地理分布式多级 L2 缓存同步。

### 2. 机器学习与预测优化
- [ ] **深度学习构建耗时预测**：基于 AST 复杂度与历史数据预测任务耗时。
- [ ] **不稳定性测试（Flaky Test）自动隔离**：统计学自动识别并隔离非确定性测试。
- [ ] **预测性预热编译**：利用空闲 CPU 预先编译可能被修改的关联包。

### 3. 可观测性与团队协作
- [ ] **OpenTelemetry 分布式链路追踪**：全链路追踪构建任务与网络节点。
- [ ] **团队效能 Web 仪表板**：可视化统计团队构建加速比与缓存命中率。
- [ ] **云资源成本计算器**：实时计算节省的算力与存储成本。

### 4. 插件生态体系
- [ ] **WebAssembly 插件引擎**：通过 Extism/WASI 安全运行沙箱化自定义工具链插件。
- [ ] **插件应用市场 (Marketplace)**：去中心化数字签名插件分发平台。

---

## 🏰 长期愿景 (v1.0+) — 核心重点：企业级安全与零信任

### 1. 企业级安全与零信任构建
- [ ] **MicroVM 硬件级隔离**：在超轻量级 Firecracker 虚拟机中执行不可信构建。
- [ ] **企业单点登录 (SSO / OIDC) 与 RBAC**：细粒度权限控制与合规审计日志。
- [ ] **SLSA Level 3 供应链合规**：生成防篡改的 in-toto attestation 与密码学 SBOM。

### 2. 全球化通用编译与快取
- [ ] **跨语言函数级 AST 增量缓存**：跨语言细粒度函数级增量重编译。
- [ ] **全球 P2P 产物分发网络**：基于 BitTorrent 原理的超大规模 CI 制品快速分发。
- [ ] **自主持续优化智能体**：AI 自主微调构建参数与编译标志。
