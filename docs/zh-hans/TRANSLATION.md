# 文档翻译与本地化贡献指南

> 🌐 我们热烈欢迎社区贡献者将 Fish 文档翻译为**任意语言**。

本文档介绍了翻译流程、公开透明政策以及贡献规范。

## 翻译范围

仅适用于 **文档内容**（`docs/` 目录下的 Markdown 文件）。

- **源代码、测试用例、代码标识符与 Git 提交信息** 必须保持 **100% 英文**。
- **CLI 命令、参数标志（--flag）、代码块与配置键名** 禁止翻译。

## 贡献者友好政策

1. **支持增量与部分翻译**：无需一次性翻译整篇长文，翻译单个小节同样受到欢迎。
2. **无需本地配置 Rust 环境**：可直接在 GitHub Web 界面点击编辑图标完成提交。
3. **快速审核流程**：文档翻译与勘误 PR 会得到优先处理与快速合并。
