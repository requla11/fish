# 支持的语言后端

Fish 为 11+ 种主流编程语言工具链提供了原生的构建编排适配器：

- [Rust](rust.md) - Cargo 与 rustc 深度集成
- [Go](go.md) - Go 模块与工具链
- [TypeScript / JavaScript](typescript.md) - Node.js, npm, pnpm, yarn, bun
- [Python](python.md) - pyproject.toml, uv, pytest
- [C / C++](cc.md) - CMake, Make, Clang, GCC, MSVC
- [Docker](docker.md) - 容器化构建编排
- [Java / Kotlin](java.md) - Maven 与 Gradle
- [Dotnet](dotnet.md) - .NET SDK 与 MSBuild
