# 示例项目与多语言入门模板

探索 Fish 工作区中包含的生产级入门示例。

## 现有示例列表
1. **`examples/polyglot-demo`**: 包含 Rust TCP 后端、Go 微服务、TypeScript 前端及 Docker Compose 的多语言栈。
2. **`examples/ai-microservices`**: 结合 Rust 高速分词器、Python FastAPI 推理服务与 Go API 网关的 AI 微服务。
3. **`examples/fullstack-wasm`**: 结合 Rust WebAssembly 核心、TypeScript 客户端与 C++ 原生计算加速器的全栈应用。

## 运行示例
```bash
cd examples/ai-microservices
fish build
fish test
```
