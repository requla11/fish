# 版本发布 v0.3.0 — 三引擎架构、11 种语言后端、多语言示例与极致性能

> ⚠️ **真实性说明（追溯补充）：** 本历史发布说明描述了**从未合并到代码库中**的组件（`go/` 服务、`py/` AI 引擎、VS Code 扩展、gRPC 传输）。在编写之时，它们属于未来规划。Fish 目前仍为纯 Rust 编写的工作区；有关实际交付内容请参阅 [architecture.md](/zh-hans/architecture)。

## 📌 概述

本次发布正式确立 **Fish v0.3.0 Release**，引入完整的三引擎架构、11 种生产级语言后端、真实多语言参考示例、完善的 5 种语言文档体系以及深度性能优化。

---

## 🚀 核心亮点与特性

### 1. 🏗️ 三引擎架构 (36 个 Crates)
- **Rust 核心 (Rust 2024, MSRV 1.88+)**：完全解耦的 DAG 合并器、Chase-Lev 工作窃取调度器、GNU Jobserver 进程池、基于 ZSTD 压缩的内容寻址存储 (CAS)，以及多层 L1/L2 缓存。
- **Go 分布式服务 (`go/`)**：高吞吐量 Coordinator、P2P 网状路由器、Worker 网关以及基于利特尔法则 (Little's Law) 优化的 Kubernetes 弹性伸缩器。
- **Python AI 引擎 (`py/`)**：实时任务耗时预测器、投机性预热 (speculative pre-warming) 以及预测性 AST 自动修复。
- **VS Code 扩展 (`vscode-extension/`)**：原生 TypeScript 扩展，集成 LSP 语言服务器与实时 DAG 任务可视化。

### 2. 🌐 完整的 11 种语言后端
- **自动探索与零配置编排 (Zero-Config)**：
  - `Rust`（Cargo 元数据、cargo-nextest、流水线式 rmeta）。
  - `C/C++`（GCC、Clang、MSVC 自动探测与 depfiles 依赖文件）。
  - `Go`（go.mod、go build、go test、go vet）。
  - `TypeScript/JavaScript`（npm、pnpm、yarn、bun、tsc）。
  - `Python`（pyproject.toml、pytest、uv、pex 打包）。
  - `Java`（Maven 与 Gradle 深度集成）。
  - `.NET`（dotnet CLI，自动识别 .csproj、.sln）。
  - `Swift`（Package.swift、swift build）。
  - `Dart`（pubspec.yaml、dart test、dart compile）。
  - `Zig`（build.zig、zig build）。
  - `Docker`（多阶段 Dockerfile 与 Compose 编排）。

### 3. ⚡ 极致性能与 Benchmark 表现
经 **Criterion** 基准测试套件验证：
- **DAG 拓扑排序**：通过零内存分配的位图直接索引，在 50 至 1,000 个任务规模下**延迟降低 25.5% – 41.6%**。
- **L1 内存并发缓存**：通过跳过磁盘 I/O，重复查询的**缓存匹配速度提升 50.2%**（`55.08 µs` $\to$ `27.57 µs`）。
- **调度器前瞻预测**：反向拓扑动态规划（$O(V+E)$ 单次遍历），即时计算最长尾部路径与关键路径评分。
- **Zero-Copy I/O**：子进程 stdout/stderr 缓冲区的直接 UTF-8 所有权转移。
- **Release Profile 编译**：全局胖链接时优化 (`lto = "fat"`)、`opt-level = 3`、`codegen-units = 1`。

### 4. 💡 多语言参考架构 (`examples/`)
- **`examples/ai-microservices`**：Rust 分词器 + Python FastAPI 推理 + Go 网关（热缓存构建：**0.46s**）。
- **`examples/fullstack-wasm`**：Rust WASM 核心 + TypeScript 客户端 + C++ 原生加速器（热缓存构建：**0.18s**）。
- **`examples/polyglot-demo`**：采用 Docker 编排的全栈微服务架构。

## 📦 主要变更
- 针对 GCC/Clang/MSVC 工具链规范化了 Windows UNC 路径前缀。
- 在远程缓存测试框架中实现了无竞争条件的临时端口分配。
- 集成了带两阶段 GC 清理的内存 L1 并发缓存。
- 在 `fish init` 中为全部 11 种后端生态添加了全面的自动探测支持。
