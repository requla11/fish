# Fish 專案發展路線圖 (Roadmap)

> 🌐 **翻譯與貢獻：** 想用您的母語翻譯或完善本文件？請參閱 [翻譯指南](TRANSLATION.md)。

本文件闡述了 Fish 專案的戰略發展路線圖，涵蓋已完成里程碑、近期目標、中期規劃以及長期遠景。

---

## 🎯 專案願景

Fish 致力於成為多語言單體大倉（Polyglot Monorepo）與分散式開發環境中效能最高、最安全且對開發者最友善的建置編排系統。目前 Fish 是一個**純 Rust 工作區**；早期版本中描述的 Python 和 Go 服務層屬於未來規劃工作，而非目前已發布代碼。

---

## 🚀 目前里程碑 (v0.2.x) — 已完成

### 第一階段：核心引擎與多語言基石
- [ ] **三引擎架構**：*規劃中，尚未實現。* 目前僅存在 Rust 高效能核心；倉庫中尚無 Python AI 或 Go 雲端服務。
- [x] **11 種後端語言支援**：Rust、Go、TypeScript/Node.js、Python、C/C++、Docker、Java、.NET、Swift、Dart、Zig。
- [ ] **通用 Protobuf 契約**：*僅為草案。* `build.proto`、`ai.proto` 與 `coordinator.proto` 位於 `proto/` 下，但尚未被任何 crate 引用（工作區暫無 gRPC 依賴）。
- [x] **Blake3 CAS 與兩階段修剪**：高吞吐內容定址製品儲存，支援 Zstandard 壓縮。
- [x] **GNU Jobserver 排程整合**：跨編譯器全域執行緒權杖協調，防止 CPU/記憶體過載。
- [x] **CI/CD 工作流程產生器**：支援 GitHub Actions、GitLab CI、CircleCI、Bitbucket。
- [x] **5 語言官方文件體系**：全面上線 GitHub Pages（英語、中文繁體、中文簡體、日語、越南語）。

## ⚡ 短期目標 (v0.3.x) — 核心重點：開發體驗與協定通道

### 1. IDE 與編輯器深度整合
- [x] **VS Code 官方擴充套件**：互動式 DAG 相依圖視覺化、一鍵執行建置任務與內嵌錯誤診斷。
- [x] **JetBrains 外掛套件**：適用於 CLion、IntelliJ IDEA 與 Rider 的原生外掛，整合 DAG ToolWindow 與 LSP。
- [x] **LSP (語言伺服器協定) 橋接**：`fish.toml` 智慧補全與工作區即時診斷。

### 2. 高效能 IPC 與通訊協定
- [x] **常駐程式 IPC 資料流**：Rust CLI 與 Python AI 之間亞毫秒級 JSON-RPC 管道。
- [x] **gRPC Remote Execution API (REAPI)**：支援標準分散式遠端執行協定 v2。
- [x] **eBPF 檔案系統追蹤**：Linux 核心層精準擷取輸入輸出檔案變動，自動探索動態相依性。

### 3. 智慧診斷工具最佳化
- [x] **AI 互動式 Doctor 醫生**：主動偵測環境問題並提供自動修復指令 (`fish doctor --fix`)。
- [x] **TUI 終端介面升級**：即時 CPU/RAM 監控圖表與多任務瀑布流展示。

> **v0.3.x 里程碑達成 (2026-08-21)：** 全部 8/8 項開發者體驗與底層通訊協定目標已 100% 達成並通過全面測試。

## 🌟 中期目標 (v0.4.x - v0.5.x) — 核心重點：雲原生分散式與 AI

### 1. 雲原生分散式基礎設施
- [ ] **Kubernetes Operator (Go)**：根據建置負載動態伸縮分散式 Worker Pod 叢集。
- [ ] **競價執行個體（Spot Instance）彈性最佳化**：節點被回收時任務無損遷移。
- [ ] **跨地域 P2P 快取分发**：地理分散式多級 L2 快取同步。

### 2. 機器學習與預測最佳化
- [x] **深度學習建置耗時預測**：基於 AST 複雜度與歷史數據預測任務耗時。
- [x] **不穩定性測試（Flaky Test）自動隔離**：統計學自動識別並隔離非確定性測試。
- [x] **預測性預熱編譯**：利用閒置 CPU 預先編譯可能被修改的關聯套件。

### 3. 可觀測性與團隊協作
- [ ] **OpenTelemetry 分散式鏈路追蹤**：全鏈路追蹤建置任務與網路節點。
- [ ] **團隊效能 Web 儀表板**：視覺化統計團隊建置加速比與快取命中率。
- [ ] **雲端資源成本計算器**：即時計算節省的算力與儲存成本。

### 4. 外掛生態體系
- [ ] **WebAssembly 外掛引擎**：透過 Extism/WASI 安全執行沙箱化自訂工具鏈外掛。
- [ ] **外掛應用市集 (Marketplace)**：去中心化數位簽章外掛發佈平台。

## 🏰 長期願景 (v1.0+) — 核心重點：企業級安全與零信任

### 1. 企業級安全與零信任建置
- [ ] **MicroVM 硬體級隔離**：在超輕量級 Firecracker 虛擬機器中執行不可信建置。
- [ ] **企業單一登入 (SSO / OIDC) 與 RBAC**：細粒度權限控制與合規稽核日誌。
- [ ] **SLSA Level 3 供應鏈合規**：產生防竄改的 in-toto attestation 與密碼學 SBOM。

### 2. 全球化通用編譯與快取
- [ ] **跨語言函式級 AST 增量快取**：跨語言細粒度函式級增量重編譯。
- [ ] **全球 P2P 產物分發網路**：基於 BitTorrent 原理的超大規模 CI 製品快速分發。
- [ ] **自主持續最佳化智慧體**：AI 自主微調建置參數與編譯旗標。
