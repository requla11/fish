# 文件翻譯與本地化貢獻指南

> 🌐 我們熱烈歡迎社群貢獻者將 Fish 文件翻譯為**任何語言**。

本文件介紹了翻譯流程、公開透明政策以及貢獻規範。

## 翻譯範圍

僅適用於 **文件內容**（`docs/` 目錄下的 Markdown 檔案）。

- **原始碼、測試案例、程式碼識別碼與 Git 提交資訊** 必須保持 **100% 英文**。
- **CLI 指令、參數旗標（--flag）、程式碼區塊與設定鍵名** 禁止翻譯。

## 貢獻者友善政策

1. **支援增量與部分翻譯**：無需一次性翻譯整篇長文，翻譯單個小節同樣受到歡迎。
2. **無需本機設定 Rust 環境**：可直接在 GitHub Web 介面點擊編輯圖示完成提交。
3. **快速審核流程**：文件翻譯與勘誤 PR 會得到優先處理與快速合併。
