# 範例專案與多語言入門範本

探索 Fish 工作區中包含的生產級入門範例。

## 現有範例列表
1. **`examples/polyglot-demo`**: 包含 Rust TCP 後端、Go 微服務、TypeScript 前端及 Docker Compose 的多語言棧。
2. **`examples/ai-microservices`**: 結合 Rust 高速分詞器、Python FastAPI 推理服務與 Go API 閘道器的 AI 微服務。
3. **`examples/fullstack-wasm`**: 結合 Rust WebAssembly 核心、TypeScript 客戶端與 C++ 原生計算加速器的全棧應用。

## 運行範例
```bash
cd examples/ai-microservices
fish build
fish test
```
