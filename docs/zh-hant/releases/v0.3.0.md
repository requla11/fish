# 版本發布 v0.3.0 — 三引擎架構、11 種語言後端、多語言範例與極致效能

> ⚠️ **真實性說明（追溯補充）：** 本歷史發布說明描述了**從未合併至程式碼庫中**的元件（`go/` 服務、`py/` AI 引擎、VS Code 擴充套件、gRPC 傳輸）。在撰寫之時，它們屬於未來規劃。Fish 目前仍為純 Rust 編寫的工作區；有關實際交付內容請參閱 [architecture.md](/zh-hant/architecture)。

## 📌 概述

本次發布正式確立 **Fish v0.3.0 Release**，引入完整的三引擎架構、11 種生產級語言後端、真實多語言參考範例、完善的 5 種語言文件體系以及深度效能優化。

---

## 🚀 核心亮點與特性

### 1. 🏗️ 三引擎架構 (36 個 Crates)
- **Rust 核心 (Rust 2024, MSRV 1.88+)**：完全解耦的 DAG 合併器、Chase-Lev 工作竊取調度器、GNU Jobserver 行程池、基於 ZSTD 壓縮的內容定址儲存 (CAS)，以及多層 L1/L2 快取。
- **Go 分散式服務 (`go/`)**：高吞吐量 Coordinator、P2P 網狀路由器、Worker 閘道以及基於利特爾法則 (Little's Law) 優化的 Kubernetes 彈性伸縮器。
- **Python AI 引擎 (`py/`)**：即時任務耗時預測器、投機性預熱 (speculative pre-warming) 以及預測性 AST 自動修復。
- **VS Code 擴充套件 (`vscode-extension/`)**：原生 TypeScript 擴充套件，整合 LSP 語言伺服器與即時 DAG 任務視覺化。

### 2. 🌐 完整的 11 種語言後端
- **自動探索與零設定編排 (Zero-Config)**：
  - `Rust`（Cargo 元資料、cargo-nextest、管線式 rmeta）。
  - `C/C++`（GCC、Clang、MSVC 自動探測與 depfiles 相依性檔案）。
  - `Go`（go.mod、go build、go test、go vet）。
  - `TypeScript/JavaScript`（npm、pnpm、yarn、bun、tsc）。
  - `Python`（pyproject.toml、pytest、uv、pex 打包）。
  - `Java`（Maven 與 Gradle 深度整合）。
  - `.NET`（dotnet CLI，自動辨識 .csproj、.sln）。
  - `Swift`（Package.swift、swift build）。
  - `Dart`（pubspec.yaml、dart test、dart compile）。
  - `Zig`（build.zig、zig build）。
  - `Docker`（多階段 Dockerfile 與 Compose 編排）。

### 3. ⚡ 極致效能與 Benchmark 表現
經 **Criterion** 基準測試套件驗證：
- **DAG 拓撲排序**：透過零記憶體配置的點陣圖直接索引，在 50 至 1,000 個任務規模下**延遲降低 25.5% – 41.6%**。
- **L1 記憶體並行快取**：透過跳過磁碟 I/O，重複查詢的**快取匹配速度提升 50.2%**（`55.08 µs` $\to$ `27.57 µs`）。
- **調度器前瞻預測**：反向拓撲動態規劃（$O(V+E)$ 單次遍歷），即時計算最長尾部路徑與關鍵路徑評分。
- **Zero-Copy I/O**：子行程 stdout/stderr 緩衝區的直接 UTF-8 所有權轉移。
- **Release Profile 編譯**：全域胖連結時優化 (`lto = "fat"`)、`opt-level = 3`、`codegen-units = 1`。

### 4. 💡 多語言參考架構 (`examples/`)
- **`examples/ai-microservices`**：Rust 斷詞器 + Python FastAPI 推理 + Go 閘道（熱快取構建：**0.46s**）。
- **`examples/fullstack-wasm`**：Rust WASM 核心 + TypeScript 客戶端 + C++ 原生加速器（熱快取構建：**0.18s**）。
- **`examples/polyglot-demo`**：採用 Docker 編排的全端微服務架構。

### 5. 📚 5 種語言文件在地化
- 完整 VitePress 文件體系，100% 涵蓋所有功能與架構：
  - 🇺🇸 英語 (`en`)
  - 🇻🇳 越南語 (`vi`)
  - 🇨🇳 簡體中文 (`zh-hans`)
  - 🇹🇼 繁體中文 (`zh-hant`)
  - 🇯🇵 日語 (`ja`)

## 📦 主要變更
- 針對 GCC/Clang/MSVC 工具鏈正規化了 Windows UNC 路徑前置詞。
- 在遠端快取測試架構中實作了無競爭條件的臨時連接埠分配。
- 整合了帶兩階段 GC 清理的記憶體 L1 並行快取。
- 在 `fish init` 中為全部 11 種後端生態新增了全面的自動探測支援。
