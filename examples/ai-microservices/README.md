# AI Microservices Monorepo Example

Demonstrates a coordinated polyglot AI pipeline managed by Fish:
- **Rust Tokenizer (`rust-tokenizer`)**: Ultra-fast text tokenization engine.
- **Python Inference (`python-inference`)**: Model prediction service.
- **Go Gateway (`go-gateway`)**: High-concurrency edge API reverse proxy.

## Build and Test
```bash
fish build
fish test
```
