# Fullstack WebAssembly Monorepo Example

Demonstrates building high-performance browser and native applications:
- **Rust Wasm Core (`wasm-core`)**: Compiles to WebAssembly module.
- **TypeScript Client (`web-client`)**: Web UI integrating the Wasm compute module.
- **C++ Native Calc (`native-calc`)**: Native C++ accelerator backend.

## Build and Test
```bash
fish build
fish test
```
